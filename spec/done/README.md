# done

Specs whose feature has actually shipped.

A spec moves here when the thing it describes is **built and verified**, not
when the spec is finished being written. `spec/` holds decisions waiting to be
built; `spec/in-progress/` holds decisions still being argued; this folder holds
decisions that are now facts about the code.

Nothing here is archived or frozen. These are the files to read when asking
*why is it like this* — and the ones to change, deliberately, when it stops
being like this.
